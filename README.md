# Modes Atelier

Explorateur de modes musicaux cinématiques dans le navigateur.

Outil léger 100 % client-side pour compositeurs, musiciens et cinéastes : choisissez une note fondamentale et un mode (Ionien, Dorien, Phrygien, Lydien, Mixolydien, Éolien, Locrien), visualisez les notes sur un clavier virtuel, écoutez la gamme et lisez la description.

## Démo

[Ouvrir la démo](https://salimadour31-boop.github.io/modes-atelier/) (GitHub Pages)

## Usage

1. Ouvrez `index.html` dans un navigateur moderne (ou la démo).
2. Choisissez la langue (FR / EN / TZM).
3. Sélectionnez la note fondamentale et le mode.
4. Cliquez sur « Jouer la gamme » ou sur les touches du clavier pour écouter.
5. Les notes de l'échelle sont surlignées.

Tout fonctionne hors ligne après le chargement. Aucune donnée n'est envoyée.

## Fonctionnalités

- 7 modes diatoniques avec descriptions cinématiques
- Clavier virtuel interactif (2 octaves simplifiées)
- Lecture audio via Web Audio API
- Multilingue : français, anglais, tamazight (Taqbaylit approximatif)
- Interface sombre, responsive, légère
